# Loja Project 🚀

Sistema de Gerenciamento Comercial Inteligente focado em automação, IA e produtividade para pequenos e médios negócios.

## 🌟 Visão Geral
O **Loja Project** é uma solução de backend robusta desenvolvida com **FastAPI**, que integra ferramentas de **OCR (Reconhecimento Óptico de Caracteres)** e **Inteligência Artificial (LLMs)** para transformar processos manuais em fluxos de trabalho automatizados.

## 🛠️ Tecnologias Principais
- **Backend:** Python 3.11+ | FastAPI | Pydantic v2
- **Banco de Dados:** SQLAlchemy | PostgreSQL | Alembic (Migrações)
- **Inteligência:** EasyOCR | Ollama | Open Interpreter
- **Infraestrutura:** Docker | Docker Compose

## 📋 Funcionalidades Atuais
- [x] **OCR de Notas Fiscais:** Extração automática de produtos e valores a partir de imagens.
- [x] **Gestão de Estoque:** Controle de entradas e saídas de mercadorias.
- [x] **Módulo de Orçamentos:** Criação e acompanhamento de propostas comerciais.
- [x] **Integração com LLM:** Suporte a chat e análise de dados via IA local (Ollama).

## 🚀 Nova Estratégia de Desenvolvimento
Estamos em uma fase de modernização e expansão:
1. **Modernização:** Migração total para Pydantic v2 e refatoração da arquitetura de dados.
2. **Conectividade:** Implementação de integração nativa com WhatsApp para envio de orçamentos.
3. **Inteligência de Negócio:** Dashboards gerenciais e sugestões de compra baseadas em IA.
